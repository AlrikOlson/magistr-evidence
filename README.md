# Magistr interface iteration evidence

Dated screenshot reviews of the Magistr desktop and website, one folder per
iteration. Each folder holds the captures, their source-bound JSON receipts and
the human review (`review.json` / `REVIEW.md`). The history of this repository is
the folder `docs/evidence/desktop-iterations` as it was recorded inside the
[Magistr repository](https://github.com/AlrikOlson/magistr) until 21 October
2026; it is mounted there as a submodule at the same path.

Add a new iteration by committing its folder here, then update the submodule
pointer in Magistr. Never edit a reviewed image; add a new dated folder.
